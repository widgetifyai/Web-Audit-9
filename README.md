# Website Health Check

Build a premium, AI-powered Website Audit platform for Widgetify that allows users to analyze any public website and receive a comprehensive, actionable report. The experience should feel fast, professional, and trustworthy, with a polished interface inspired by modern SaaS products.

The platform should prioritize simplicity, speed, and clarity, making complex website analysis easy for business owners, marketers, founders, and developers to understand.

Design Direction

Create a clean, minimal, and premium interface with generous spacing, elegant typography, subtle animations, rounded components, and a consistent visual hierarchy.

The design should inspire confidence and make the audit process feel effortless.

Use a dark-first theme with a modern color palette, smooth transitions, and responsive layouts across desktop, tablet, and mobile.
